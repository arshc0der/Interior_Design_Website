# Security Policy

## Supported versions

This is a static website template (HTML and CSS). Only the latest version on the `main` branch is supported.

## Reporting a vulnerability

If you find a security problem (for example an unsafe link, an exposed secret, or an unsafe script in a pull request), please **do not open a public issue**.

Instead:

1. Open the repository's **Security** tab and choose **Report a vulnerability** (private reporting), or
2. Contact the maintainer, [@arshc0der](https://github.com/arshc0der), through GitHub.

Please include what you found, where it is, and steps to reproduce it. We will reply as soon as we can.

## For contributors

- Never commit passwords, API keys or personal data.
- Use `https://` links for external resources.
- Add `rel="noopener noreferrer"` to links that use `target="_blank"`.
- Load third-party scripts only from trusted sources and explain why they are needed in your pull request.
